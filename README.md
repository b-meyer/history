# history

One static site with two views, `/map` and `/wiki`, over a shared knowledge graph of people, works, places and events. Every claim on the map carries its sources and a reviewed confidence.

## Commands

Run from the repo root with Vite+ (`vp`):

| Command        | Does                                |
| -------------- | ----------------------------------- |
| `vp install`   | Install dependencies                |
| `vp run dev`   | Start the site dev server           |
| `vp run build` | Build the site to `apps/site/dist/` |
| `vp check`     | Format, lint and type-check         |
| `vp run test`  | Run the tests                       |
| `vp run ready` | Check, test and build before a push |
